## 2. Kesenjangan Integrasi (*Integration Gaps*) yang Terdeteksi

1. **Format File Ekspor Excel (.xlsx)**:
   - *Kondisi Backend*: Endpoint `/reports/{reportType}/export` saat ini mengembalikan MIME-type `text/csv` (CSV Stream).
   - *Kondisi Frontend*: Komponen [ExportButton.vue](file:///d:/PKL%20Duta%20Media/Dutamedia-WorkPulse/frontend/src/components/shared/ExportButton.vue) mendukung parameter format `csv`. Tombol opsi `xlsx` sebaiknya disembunyikan hingga backend menambahkan parser streaming OpenXML.
2. **Kanal Pengiriman Web Push Notification**:
   - *Kondisi Backend*: Model database dan webhook trigger siap mengirim payload push event.
   - *Kondisi Frontend*: Komponen [AdminNotificationSetupTab.vue](file:///d:/PKL%20Duta%20Media/Dutamedia-WorkPulse/frontend/src/components/admin/AdminNotificationSetupTab.vue) menampilkan toggle kanal Browser Push. Namun, registrasi browser Service Worker publik (`navigator.serviceWorker.register`) dengan VAPID public key masih berstatus *client-side stub* dan belum dihubungkan ke penyedia push gateway.
